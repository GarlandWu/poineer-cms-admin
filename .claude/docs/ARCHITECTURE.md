## 2. 核心数据模型契约 (Data Models)

系统底层定义三类核心数据，位于 `src/types/schema.ts`：

### A. 解决方案 (`SolutionItem`)
用于展示各场景（如智慧园区、数据中心）的数字孪生架构与协议能力：
- `slug`: 唯一 URL 标识
- `title`: 方案名称
- `industry`: 行业分类
- `twinCapabilities`: 数字孪生功能列表（如 3D 拓扑重构、实时能耗热力图）
- `supportedProtocols`: 支持的工业采集协议（Modbus, MQTT, OPC UA 等）
- `architectureImage`: 解决方案架构拓扑图

### B. 硬件网关与设备 (`EnergyProductItem`)
用于展示工业采集硬件与选型参数：
- `modelNumber`: 产品型号
- `category`: 分类（边缘采集网关、智能电表等）
- `samplingSpecs`: 采集性能参数（通道数、上报频率、支持协议）
- `specifications`: KV 详细规格表（供电、防护等级等）
- `pdfSpecUrl`: 选型手册下载地址

### C. 客户成功案例 (`EnergyCaseStudy`)
用真实数据打动客户：
- `clientName`: 客户名称/行业
- `metrics`: 核心量化指标（节约能耗百分比、数据采集延迟、ROI 周期）
- `twinScreenshot`: 客户现场 3D 数字孪生实景截图

## 3. SEO 与移动端性能优化策略

### A. 移动端性能与交互
- **数字孪生媒体替代策略**: 移动端不直接加载重型 3D Three.js 引擎，自动转换为无缝循环的短视频 (MP4/WebM) 或 高清 WebP 帧，确保手机端帧率保持 60fps。
- **触控优化**: 底部集成常驻 `MobileBottomNav` 组件，提供【一键拨号】与【微信客服弹窗】。

### B. 百度 / Google 搜索引擎优化 (SEO)
- **预渲染 (SSG)**: 编译期自动拉取所有数据生成纯 `.html` 文件，百度蜘蛛直接抓取完整的页面文本与 `<h1-h6>` 结构。
- **动态 OpenGraph & TDK**: 为每一个产品和案例动态配置标准的 Meta 标题、描述与微信分享缩略图。
- **Sitemap & Robots**: 构建脚本自动在 `out/` 根路径生成最新的 `sitemap.xml` 与 `robots.txt`。

## 4. 自动化构建与部署流

1. **修改内容**: 管理员在本地启动 `npm run dev`，登录 Payload 后台录入产品或案例。
2. **触发编译**: 执行 `npm run build`，Next.js 会自动触发 `generateStaticParams()` 并抓取本地数据。
3. **推送到 Git**: 执行 `git push` 上传编译后的文件到托管仓库。
4. **CDN 刷新**: 腾讯云 Webify 接收到变更，自动分发最新静态页面到全国 CDN 边缘节点。
