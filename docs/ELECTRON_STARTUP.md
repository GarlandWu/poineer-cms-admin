# ⚡ 能源门户管理系统 - 快速启动指南

## 🚀 三种启动方式

### 方式 1️⃣ : 本地开发（推荐开发者）

**优点**: 实时热更新，支持调试
**缺点**: 需要安装 Node.js

```bash
# 方式 A: 使用批处理脚本（最简单）
双击运行 run-dev.bat

# 方式 B: 手动命令行
npm install
npm run electron-dev
```

---

### 方式 2️⃣ : 打包成 EXE（推荐运营团队）

**优点**: 无需 Node.js，直接运行，支持一键发布
**缺点**: 首次打包需要时间

#### 第一次打包

```bash
# 使用批处理脚本（最简单）
双击运行 build-exe.bat

# 或手动命令行
npm install
npm run build
npm run electron-build
```

#### 打包完成后

在 `dist/` 目录找到生成的 EXE 文件：
- `能源门户管理系统 Setup 0.1.0.exe` - 安装程序版（推荐）
- `能源门户管理系统 0.1.0.exe` - 便携版（无需安装）

#### 运营人员使用

1. **第一次使用**:
   - 双击 `Setup 0.1.0.exe` 安装程序
   - 按照向导完成安装
   - 安装完成后自动启动应用

2. **日常使用**:
   - 从开始菜单或桌面快捷方式启动应用
   - 或直接运行便携版 EXE

---

### 方式 3️⃣ : 直接启动已编译的 Electron（高级）

```bash
# 确保 Node.js 和 npm 已安装
npm install
npm run electron
```

**注意**: 此方式需要同时运行 Next.js 开发服务器
```bash
# 在另一个终端运行
npm run dev
```

## 📋 工作流程 (运营人员)

### 日常内容更新

```
1. 启动应用
   ↓
2. 点击 "启动 CMS" 按钮
   ↓
3. 在浏览器中编辑内容 (http://localhost:3001)
   ↓
4. 编辑完成，返回应用
   ↓
5. 点击 "构建" 按钮
   ↓
6. 点击 "启动预览" 按钮
   ↓
7. 在浏览器中预览效果 (http://localhost:5000)
   ↓
8. 确认无误后，点击 "执行发布" 按钮
   ↓
9. 确认发布（会自动 Git 提交和推送）
   ↓
10. 完成！ ✅
```

## 🎯 常见操作

### 编辑一篇新闻

1. 启动 CMS → 在浏览器打开 http://localhost:3001
2. 导航到 "News" 集合
3. 点击 "+ Create" 或 "+ New"
4. 填写标题、内容、图片等
5. 点击 "Publish" 或 "Save"
6. 关闭 CMS 标签，返回应用
7. 点击 "构建" 生成静态文件
8. 点击 "启动预览" 验证效果
9. 确认无误后点击 "执行发布"

### 修改解决方案描述

1. 启动 CMS
2. 在 CMS 中找到对应的解决方案
3. 编辑内容
4. 保存/发布
5. 构建 → 预览 → 发布

### 更新产品规格

1. 启动 CMS
2. 在 CMS 中找到产品页面的字段
3. 修改规格数据
4. 保存
5. 构建 → 预览 → 发布

## 🐛 问题排查

### 应用无法启动
- ✅ 尝试重新启动
- ✅ 检查防火墙设置
- ✅ 查看错误日志

### CMS 启动失败
- ✅ 检查 3001 端口是否被占用
- ✅ 运行 `npm install` 在 cms 目录
- ✅ 检查网络连接

### 预览无法启动
- ✅ 检查 5000 端口是否被占用
- ✅ 确保已成功执行"构建"
- ✅ 检查 out/ 目录是否存在

### 发布失败
- ✅ 检查 Git 配置
- ✅ 检查网络连接
- ✅ 检查 GitHub/GitLab 权限

## 💡 小贴士

### 快速工作流

如果每天都要更新内容：

1. 创建快捷方式：
   - 右键点击 `run-dev.bat` 或 EXE
   - 创建快捷方式到桌面

2. 设置快捷键：
   - 右键点击快捷方式 → 属性
   - 在"快捷方式"选项卡设置快捷键

3. 一键启动更新：
   - 按快捷键启动应用
   - 完成编辑和发布

### 备份数据

- CMS 数据存储在 `cms/payload.db` 中
- 建议定期备份此文件
- 网站数据在 `out/` 目录中

### 版本更新

如果开发者发布了新版本：

1. 下载新的 EXE 文件
2. 卸载旧版本（可选）
3. 运行新版本 EXE
4. 重复上述工作流
