# 不打包 EXE，直接运行方案

如果 pkg 打包有问题，运营人员可以直接运行 Node.js 应用。

## 给运营人员的步骤

### 前置条件

安装 Node.js 20 LTS：https://nodejs.org/

### 运行应用

在项目目录中打开命令行：

```bash
# 安装依赖
npm install

# 运行应用
npm run app
```

**就这样！** 应用会自动：
1. 启动 HTTP 服务
2. 打开浏览器
3. 显示操作面板

---

## 优点

✅ 零打包问题  
✅ 易于调试  
✅ 易于更新（只需 git pull）  

## 缺点

❌ 需要运营人员安装 Node.js  

---

## 推荐

如果运营人员是技术人员或可以接受安装 Node.js，这是最简单的方案。
